# 数据说明
本目录仅包含独立生成的国内电商模拟数据，非真实交易、客户或平台数据，仅供学习。
生成器：src/model.py中的demo()，固定种子20261116。
订单时间：2026年1—4月，按北京时间解释；金额单位：人民币元CNY。
渠道编码：douyin（抖系）、taobao（淘系）、jd（京系）。

orders.csv一行是一条订单商品明细，不是一个客户；traffic.csv一行是月份×产品×渠道；targets.csv一行是全店月目标。
完整字段与公式见../docs/DATA_CONTRACT.md。
生成器和全部输入CSV一同提供，可重建默认数据；普通构建只读取CSV，不修改输入。
